Deployed on **Railway** with full CI/CD pipeline.

## 🚀 Quick Start

```bash
# 1. Clone
git clone https://github.com/alam025/sentiment-analysis-api.git
cd sentiment-analysis-api

# 2. Install
pip install -r requirements.txt

# 3. Run
python main.py
```
